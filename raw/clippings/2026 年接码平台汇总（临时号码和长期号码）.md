很多时候我们需要临时用到一个手机号，比如注册海外网站、测试短信验证码接口，或者注册账号验证实验。“接码平台”就成了省事的选择。所谓接码平台，就是提供虚拟号码或者真实号码接收短信验证码的服务。我之前也踩过不少坑，有的平台压根收不到短信，有的延迟半天才到，而且现在好多平台都要二验，最后整理出几个稳定、亲测可用的平台，分享给大家。

说明：以下按 推荐 / 备用 便于查阅。 实际可用性、号码质量、可接收平台、地区覆盖和短信保留时间可能会随时变化，请以网站当前页面为准。

# 1.longsms （优先推荐）

**网址： [https://longsms.net/](https://longsms.net/)**

- 提供美国，加拿大，英国，荷兰，瑞典等五个国家的长期虚拟号码和真实号码
- 提供美国，英国，香港，荷兰，等一百多个国家的虚拟号码
- 支持网页端和 api 接入，界面友好，API 文档清晰
- 实测注册 WhatsApp ，LinkedIn ，gmail ，TG 都能正常收到验证码
- 亲测体验：验证码接收速度很快，可接收验证码或其他短信，大多数情况下 10 秒内能到，长期号码接码率 90%以上。
- 优势：支持长期租赁，单次最高可租赁 360 天并且价格便宜，若需二验首选
- 支持少量充值，号码价格较便宜
- 支持中文

# 2.5SIM （备用首选）

**网址： [https://5sim.net/](https://5sim.net/)**

- 提供美国，英国，香港，荷兰，等一百多个国家的虚拟号码
- 支持网页端和 api 接入，界面友好，API 文档清晰
- 实测注册 Google 、LinkedIn 都能正常收到验证码
- 亲测体验：验证码接收速度一般，大多数情况下 30 秒到一分钟内能到，接码率 60%左右
- 不支持长期租赁，仅能租赁 20 分钟的临时号码
- 支持少量充值，号码价格较便宜
- 支持中文

# 3.SMS-Man

**网址： [https://sms-man.com/](https://sms-man.com/)**

- 提供美国，英国，香港，荷兰，等 365 个国家的虚拟号码，覆盖国家最广
- 支持网页端和 api 接入，API 文档清晰
- 实测注册 Google 、Twitter 都能正常收到验证码，稳定性不错
- TG 机器人集成，可以直接在 TG 里购买号码和接收验证码
- 亲测体验：验证码接收速度还行，大多数情况下 30 秒内能到
- 有低消，最低充值 10$,且号码价格较贵
- 支持中文

# 4.HeroSMS

**网址： [https://hero-sms.com/](https://hero-sms.com/)**

- SMS-Activate 的「继任者」，风评一般
- 提供美国，英国，香港，荷兰，哥伦比亚等 180+个国家的虚拟号码
- 支持网页端和 api 接入
- 实测注册 Google 、TG 都能正常收到验证码
- 亲测体验：验证码接收速度一般，大多数情况下 2 分钟内能到，接码率较低，30%左右
- 支持少量充值，号码价格较便宜
- 支持中文

# 5.TextVerified

**网址： [https://www.textverified.com/](https://www.textverified.com/)**

- 提供来自真实运营商的美国 Non-VoIP 号码
- 支持网页端和 api 接入
- 实测注册 Google 、TG ，WhatsApp 都能正常收到验证码
- 亲测体验：验证码接收速度较快，大多数情况下 10-30 秒内能到，接接码率 90%左右
- 支持少量充值，号码价格贵
- 不支持中文

# 6.Receive-SMS-Online

**网址： [https://receive-sms-online.info/](https://receive-sms-online.info/)**

- 支持美国、西班牙、罗马尼亚、英国、德国、法国、俄罗斯等国家的免费号码和其他 51 个国家的付费号码
- 不支持 api 接入
- 实测免费号码注册 Google 、TG ，WhatsApp 几乎收不到验证码，付费号码都能收到验证码
- 亲测体验：免费号码几乎收不到验证码，付费号码验证码接收速度一般
- 无需注册，付费号码很贵
- 不支持中文
